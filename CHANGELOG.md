# Changelog

## 0.1.0

Initial public code release alongside the existing research project page.

- Modular workflow services for planning, execution, repair and learning.
- Enforced skill reuse with partial graph entry and node-ID recovery.
- Programmatic observation-based edge checks supplied to two-stage assessment.
- Literal repair fields that preserve observation text safely.
- Versioned working memory with precise rollback and source-page attribution.
- Domain-scoped skills, repair experience, subgoal guidance and component types.
- Producer-only attempt assets and provenance records.
- Verified replacement input and retained infeasibility responses.
- Local WebArena setup/check scripts and a bundled BrowserGym fork.
- Offline regression tests and clean source/Python distribution packaging.

This release excludes provider keys, browser sessions, historical runs,
prelearned skills or memories, and an official WebArena ground-truth evaluator.
