# BrowserGym core

This package provides `browsergym.core`, which provides the core functionalities of [BrowserGym](https://github.com/ServiceNow/BrowserGym).

This bundled fork is versioned `0.10.2+skilltracer.2`. SkillTracer modifies
navigation/observation timing, browser timeout handling, field replacement and
verification, and infeasibility reporting. Install this directory through the
repository's setup script rather than substituting the upstream package.
The upstream license notice is retained in `NOTICE`; see `LICENSE` for the
Apache-2.0 license text.

## Setup

1. Install the package
```sh
pip install browsergym-core
```
